Installing on Linux.

Ubuntu, Debian, Mint, Pop!_OS, Zorin, elementary: open the .deb file and choose Install, or in a terminal:

sudo apt install ~/Downloads/RowVision-*.deb

RowVision then appears in your app menu.

Fedora, Arch, openSUSE and others: use the AppImage. In a terminal, go to where it saved, make it runnable and open it:

cd ~/Downloads
chmod +x RowVision-*.AppImage
./RowVision-*.AppImage

Runs on 64-bit Intel and AMD computers with Linux from 2020 on, such as Ubuntu 20.04 or Fedora 32 and newer. If the AppImage will not start, ./RowVision-*.AppImage --appimage-extract-and-run opens it another way.
