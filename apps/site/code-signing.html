Code signing policy.

How the Windows installers are signed, and who can sign them.

What is signed
Only RowVision’s own installer and programs, built from the public source by GitHub Actions. Other people’s programs inside it, such as ffmpeg, are included unchanged.
Committers and reviewers
Fionn Mowlds. Changes from anyone else are reviewed before they go in.
Approvers
Fionn Mowlds approves every release by hand before it is signed.
Privacy
The app sends nothing about you or your clips. It fetches its measuring models once, and checks for new versions, which you can turn off. The privacy policy has the details.
Taking it off
Uninstall it from Windows Settings, Apps. Your clips are kept unless you delete them.
